### 🌱 [AgroFarm AI](https://github.com/abdulrehmanml/agrofarm-ai)

An agriculture advisory application combining **Generative AI, RAG, and Agentic AI** to provide grounded, field-aware farming guidance.

**Stack:** Python • Gemini • ChromaDB • RAG • Streamlit

<p>
  <a href="https://github.com/abdulrehmanml/agrofarm-ai">Repository</a>
  &nbsp;•&nbsp;
  <a href="https://agrofarm-ai.streamlit.app/">Live Demo</a>
</p>

<p align="center">
  <a href="https://github.com/abdulrehmanml/agrofarm-ai">
    <img src="assets/agrofarm_ai.png" alt="AgroFarm AI" width="82%">
  </a>
</p>

<details>
  <summary><strong>Technical Details</strong></summary>

> **Architecture:** Generative AI • RAG • Agentic AI
>
> **Core Components:** Gemini • ChromaDB • TF-IDF • Open-Meteo • Streamlit
>
> **RAG Flow:** User Question → Retrieval → Relevant Agronomy Context → Gemini → Grounded Answer
>
> **Agent Flow:** Field Data + Weather + RAG Knowledge → Gemini Reasoning → Recommendation → Human Approval
>
> **Controls:** Source Grounding • Human Approval • Decision Logging

</details>
